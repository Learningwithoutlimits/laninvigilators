Enter the admin password to manage the timetable.

Uploads and changes are switched on for Lancaster Academy only at the moment. This school's timetable will appear here once it has been set up.

Click a box and type to change it. Type a room or duty (for example Hall, Gym or Roving). Type N/A if the person is not available. Leave it empty for no duty. The Start time and Duration columns (not including extra time) apply to every room in that exam row. Use + to add another exam row to a session, the arrows to move a row up or down within its day (including between AM and PM), and ✕ to remove a row. Press Save and publish when you have finished.
